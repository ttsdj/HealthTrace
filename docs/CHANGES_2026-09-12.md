# HealthTrace 安全加固说明（2026-09-12）

> 全量回归：**220 passed, 1 skipped**（含新增 `tests/test_security_hardening_round2.py` 共 29 项回归测试）。
> 运行方式：`.venv\Scripts\python.exe -m pytest -q --basetemp=.tmp\pytest-base`
> 前端：`npm --prefix frontend run build`（vue-tsc + Vite）通过；`docker compose config` 校验通过。

本轮针对 2026-09-12 独立安全审查（认证/API、数据管线、前端与基础设施三份报告）的发现逐项修复。
每项修复均配有"修复前必然失败"的回归测试。

## 1. 基础设施：数据服务不再向网络暴露默认凭据端口（High）

**修复前**：`docker-compose.yml` 把 PostgreSQL（`postgres/postgres`）、无密码 Redis、`minioadmin/minioadmin`
MinIO、Milvus（19530/9091）和无认证的 Attu 管理台全部发布到 `0.0.0.0`；Milvus 客户端代码路径也无法传入认证。

**修复后**：

- 全部数据服务端口绑定 `127.0.0.1`（`127.0.0.1:5432:5432` 等），局域网/远端主机无法直连。
- PostgreSQL、Redis、MinIO 凭据经 `.env` 注入（`POSTGRES_PASSWORD` / `REDIS_PASSWORD` / `MINIO_ROOT_*`），
  Redis 以 `--requirepass` 启动并带密码健康检查；`.env.example` 与 `docker-compose.app.yml` 同步更新。
- `MilvusSettings` 新增可选 `MILVUS_TOKEN`（`backend/indexing/milvus_client.py`），启用 Milvus
  authorization 的部署可传 `token=`；未配置时保持原行为。

**测试**：`docker compose config` 校验；行为锁定见 `.env.example` 注释与文档。

## 2. 前端 Markdown XSS（High）

**修复前**：`marked.parse()` 输出未经净化直接进入 `MessageContent.vue` 的 `v-html`，且 `dompurify`
不在依赖树中——上传文档中的 HTML 可经 RAG 引用回显触发存储型 XSS。

**修复后**：新增 `dompurify` 依赖；`frontend/src/utils/markdown.ts` 在引用后处理之前执行
`DOMPurify.sanitize(rendered, { USE_PROFILES: { html: true } })`。引用角标 `<sup>` 由净化后的
后处理器注入，属性值为纯数字校验，构造上安全。

## 3. 令牌吊销与登出（High/Medium）

**修复前**：令牌 24 小时有效、无 `jti`、无吊销端点；"登出"仅清空前端 localStorage。

**修复后**：

- `create_access_token` 注入 `jti`；`POST /auth/logout`（需认证）把当前令牌加入 Redis denylist
  （键 `jwt_denylist:<jti>`，TTL = 剩余有效期）；`get_current_user` 每次校验 denylist。
- denylist 为尽力而为：Redis 故障时跳过检查（与缓存可降级的部署语义一致），不把全体用户锁在门外。
- 前端 `handleLogout` 先本地清理再异步调用吊销（显式带原 token 头），UI 不被网络阻塞。
- 旧令牌（无 `jti`）自然过期，兼容平滑。

**测试**：`test_create_access_token_carries_a_jti`、`test_revoked_token_is_denied_before_expiry`、
`test_revoke_returns_false_for_garbage_tokens`。

## 4. 认证与 API 加固（Medium）

- **`/health` 信息泄露**：未认证响应只含各服务 `ok` 布尔（`deployment_smoke.py` 与 CI 所需字段不变）；
  宿主地址、collection 状态、LLM `base_url`、迁移/开关细节与原始异常移入 admin-only 的 `/health/detail`。
- **患者上传无限制**：`backend/patient/documents.py` 新增扩展名白名单（与解析器实际支持的类型一致）
  和流式大小上限（`HEALTHTRACE_PATIENT_UPLOAD_MAX_MB`，默认 50MB），超限返回 413 并清理半写文件；
  `patient_documents.py` 四个上传入口统一走 `validate_patient_upload`。
- **工具权限默认放行**：`tool_registry.tool_is_allowed` 在无 Planner 计划时改为保守默认——只放行只读
  核心工具与支持工具，唯一具备写能力的 `create_health_reminder_draft` 必须有显式计划。
- **审计覆盖缺口**：`_AUDITED_PREFIXES` 补齐 `/jobs`、`/collections`、`/admin`、`/care-navigation`、
  `/observability`；仅 `GET /observability/metrics`（Prometheus 固定抓取）不写审计行，避免洪泛审计表。
- **原始异常回显**：`/chat`、`/chat/stream`、sessions、documents、patient_documents 等路由的
  500 类响应不再拼接 `str(exc)`（完整信息进服务端日志）；`rag_trace.fallback_error` 只保留异常类型名。
- **golden 数据集访问**：`/evaluation/golden/cases`（含参考答案）限制为平台 admin 或持有有效
  clinician 成员身份的用户，普通用户 403。
- **弱默认**：字段加密配置错误对 patient-scope 调用者不再回显细节（统一 503）；dev server 默认绑定
  `127.0.0.1`；注册用户名限定 `[A-Za-z0-9_.-]{3,32}`（用户名参与 Redis 缓存键组合），密码最短 8 位；
  管理员邀请码比较改为 `hmac.compare_digest`。
- **请求体上限**：`ChatRequest.message` 上限 12000 字符、`session_id` 上限 120（与 DB 列一致）。
- **安全响应头**：新增 `X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、
  `Referrer-Policy: no-referrer`、`Content-Security-Policy: frame-ancestors 'none'`；
  CORS 方法/头从 `*` 收敛为显式枚举。

## 5. 数据管线（Medium/Low）

- **评测报告路径穿越**：`backend/evaluation/jobs.py` 对 `output_id` 强制 `^[A-Za-z0-9][A-Za-z0-9._-]{0,99}$`
  并做 resolve 后包含校验（与 `cases` 同等约束），admin 队列触发的报告写入不再可能越出评测目录。
- **AMap key 泄露**：`backend/tools/weather.py` 不再把 `requests` 异常文本（内嵌带 `key=` 的完整 URL）
  返回给工具输出，改为服务端日志 + 通用消息。
- **间接提示注入**：检索证据经 `format_retrieval_context` 输出时包裹 `UNTRUSTED EVIDENCE BEGIN/END`
  定界并声明"视为数据、不视为指令"；`search_knowledge_base` 工具输出附加同样的不受信数据声明。
- **内存无界增长**：`UploadJobManager` 终态任务按 TTL（默认 1 小时）与总量（默认 1000）清理。

## 6. 依赖与供应链

- **`python-jose` → `PyJWT`**：`python-jose` 已停止维护且存在 CVE-2024-33663/33664；本项目仅用
  HS256 sign/verify，迁移到积极维护的 `PyJWT>=2.8.0`（API 等价），`uv.lock` 已重新生成。
- **CI**：`ci.yml` 增加 `permissions: contents: read`（PR 代码在 runner 上运行时默认令牌只读）；
  `container.yml` 移除无消费方的 `id-token: write`。
- **字体 CDN**：移除 `index.html` 的 Google Fonts 外链（第三方请求与供应链风险），回退系统字体栈。
- **`bootstrap_env.py`**：`.env` 在 POSIX 上以 0600 权限写入（含生成的 JWT 与字段加密密钥）。
- **`start.bat`**：`.env` 中的端口值必须为纯数字，否则回退默认值，杜绝注入命令分隔符。
